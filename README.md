# 🎮 Tres en línea

Juego clásico de tres en línea (Tic-Tac-Toe) para dos participantes, desarrollado con HTML, CSS y JavaScript puro.

## ✨ Funcionalidades
- Tablero interactivo de 3 × 3.
- Turnos alternados entre X y O.
- Detección automática de victoria y empate.
- Resaltado de la combinación ganadora.
- Marcador acumulado durante la sesión.
- Botón para iniciar una nueva ronda y reiniciar el marcador.
- Diseño responsive y accesible con teclado.

## 🚀 Cómo jugar
1. Abrí `index.html` en tu navegador.
2. Elegí una casilla libre para colocar tu símbolo.
3. Se alternan los turnos automáticamente.
4. Gana quien complete una línea horizontal, vertical o diagonal.
5. Presioná “Nueva partida” para jugar otra ronda.

## 🧰 Tecnologías
HTML5 · CSS3 · JavaScript (Vanilla)

No requiere instalación, dependencias ni conexión a internet.
